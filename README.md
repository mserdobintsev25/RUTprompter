# RUTprompter

Суфлёр для macOS, который подстраивает скорость прокрутки текста под
темп речи читающего и в реальном времени показывает, сколько осталось
читать и укладывается ли дубль в целевую длительность.

## Сборка и запуск

```bash
./build.sh run        # собрать build/RUTprompter.app и запустить
./build.sh install    # положить в /Applications и запустить
./build.sh check      # самопроверка логики (сопоставление речи, темп, ETA)
```

Распознавание речи работает только в собранном `.app` (`swift run`
не даёт macOS запросить доступ к микрофону). При первом «Старте» в
режиме «По голосу» macOS спросит доступ к микрофону и распознаванию.
Распознавание строго на устройстве: если для языка нет офлайн-модели,
добавьте язык в «Системные настройки → Клавиатура → Диктовка».

## Как пользоваться

- Слева — текст скрипта (автосохраняется). Разметка:
  `# Раздел` — маркер/шаг, `[ремарка]` — не читается,
  `МАША:` — метка говорящего (заглавными), не читается.
- Справа — превью: клик по слову — перейти, прокрутка трекпадом — перемотка.
- Режим «По голосу» — прокрутка следует за читающим; реплики не из
  скрипта игнорируются. «Фикс. скорость» — обычный суфлёр.
  Если распознавание недоступно, приложение само переходит на
  фиксированную скорость.
- Второй экран (HDMI) открывается автоматически, без рамки, на весь
  экран. Зеркалирование — только для него (кнопка ↔ или `M`).
  Без второго монитора: «Окно → Вывод в отдельном окне».
- Поле с мишенью — целевая длительность дубля (`0:45` или `45`).
- «Стоп» завершает дубль; «Дубли» — разбор: время, темп по ходу
  текста, места, где темп проседал или разгонялся.

Голосовых команд нет намеренно: голос только отслеживает, где
читающий находится в тексте.

### Клавиши

| Клавиша | Действие |
|---|---|
| Пробел / ⌘↩ | старт / пауза |
| ⌘. | стоп (завершить дубль, в начало) |
| ↑ ↓ | строка назад / вперёд |
| ← → (⌘[ ⌘]) | предыдущий / следующий раздел |
| + − | скорость ±10 сл/мин |
| [ ] (⌘− ⌘=) | шрифт мельче / крупнее |
| M (⌘⇧M) | зеркало второго экрана |
| Home / ⌘0 | в начало |
| Esc | пауза |

## Структура

```
Package.swift
build.sh                 — сборка .app (как у Peel)
Support/Info.plist       — описания доступа к микрофону и распознаванию
Sources/PrompterCore/    — логика без UI
  TextNormalizer.swift   — нормализация, фонетический ключ ru/en
  PrompterDocument.swift — разбор скрипта: слова, разделы, ремарки
  ScriptMatcher.swift    — сопоставление распознанной речи с текстом
  Pacing.swift           — темп (WPM), пружина прокрутки, ETA
  Takes.swift            — запись и анализ дублей
Sources/CoreChecks/      — самопроверки (`./build.sh check`)
Sources/RUTprompter/     — приложение
  AppDelegate.swift      — окна, меню, горячие клавиши
  PlaybackEngine.swift   — позиция, режимы, связь речи и прокрутки
  SpeechInput.swift      — микрофон + SFSpeechRecognizer (on-device)
  AudioDevices.swift     — выбор микрофона/канала
  PrompterCanvasView.swift — отрисовка текста (превью и вывод)
  DisplayManager.swift   — окно вывода на внешнем экране
  OperatorView.swift, SettingsView.swift, TakesView.swift — интерфейс
  Settings.swift         — темы, настройки, автосохранение
```
